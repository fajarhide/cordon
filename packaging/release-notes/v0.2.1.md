A fix for `/v1/stdio` jobs that pass `env`. Under a systemd unit with `PrivateTmp=yes` and rootless podman, 0.2.0 wrote the env file to its private temp dir, which podman could not see once it entered its own namespaces, so the job closed right after cordon answered ok. The file now goes under `CORDON_ROOT/env`, outside every owner's workspace.

```bash
curl -fsSL https://github.com/fajarhide/cordon/releases/latest/download/cordon-$(uname -m)-unknown-linux-musl.tar.gz | tar xz
sudo install cordon-$(uname -m)-unknown-linux-musl/cordon /usr/local/bin/
```
