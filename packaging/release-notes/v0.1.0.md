First release. cordon gives every user, team and AI agent its own sandbox on one server, and refuses every path out of it. No VM and no KVM.

What is in it:

- `/v1/resolve`, `/v1/run`, `/v1/artifact`, `/v1/fork` and `/v1/token` behind a bearer token.
- Two backends: a process under Landlock, or a docker or podman container with no network by default.
- Tokens scoped to an owner prefix, with an optional lifetime and a revoke endpoint.
- `cordon verify`, which fires 31 attacks at your running daemon and exits non-zero if one lands.
- TypeScript and Ruby clients under `clients/`, Apache 2.0.

The binaries below are static musl builds for x86_64 and aarch64 Linux, so one file runs on any distribution. Each archive carries the binary, the licence, the README and a systemd unit.

```bash
curl -fsSL https://github.com/fajarhide/cordon/releases/latest/download/cordon-$(uname -m)-unknown-linux-musl.tar.gz | tar xz
sudo install cordon-$(uname -m)-unknown-linux-musl/cordon /usr/local/bin/
cordon demo
```

Known limits: the host kernel is shared, so a kernel exploit gets past it, and a job's network is either none or fully open. The README says where each line is drawn.
