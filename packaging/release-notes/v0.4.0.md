`POST /v1/copy` copies files between two owners inside the daemon, so a caller that keeps an owner's files apart from the owner its jobs run in does not move every byte through itself around each job. Both owners are checked against the token's scope, both sides open with `O_NOFOLLOW`, and sizes and the destination quota are checked before anything is written. `GET /v1/files?path=` naming a file now answers that one entry, so `hash=true` hashes one file.
