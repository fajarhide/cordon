File endpoints for an owner's workspace, so a caller can read a file tree or save one edit without starting a job. `GET /v1/files` lists files with size, and sha256 with `hash=true`. `GET`, `PUT` and `DELETE /v1/file` read, write and delete one file, and `PUT` and `DELETE` take `If-Match` with a sha256. Every open walks from the workspace with `O_NOFOLLOW`, so a symlink a job plants is refused by the kernel. Two new limits: `CORDON_MAX_FILE_MB` (default 100) and `CORDON_OWNER_QUOTA_MB` (default 2048).

```bash
curl -fsSL https://github.com/fajarhide/cordon/releases/latest/download/cordon-$(uname -m)-unknown-linux-musl.tar.gz | tar xz
sudo install cordon-$(uname -m)-unknown-linux-musl/cordon /usr/local/bin/
```
